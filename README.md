# 하이파이브 잉글리쉬 (HiFive English)

1:1 화상영어 서비스 웹사이트. React + TypeScript + Vite + Tailwind CSS 기반.

## 실행 방법

```bash
npm install
npm run dev
```

`npm run build`로 프로덕션 빌드, `npm run preview`로 빌드 결과를 미리 볼 수 있습니다.

## 현재까지 구현된 범위

메인(소개) 페이지 1개만 구현되어 있습니다.

- 상단 유틸리티 바(홈 / 로그인 / ID·PW 찾기 → 로그인 시 홈 / 홈페이지관리 / 정보변경 / 로그아웃)
- 로고 + 회사명 중앙 배치, GNB(회사소개·화상영어소개·프로그램설치·커리큘럼·수강안내·강사소개·학습시스템·고객센터) — 드롭다운 포함
- 우측 고정(스크롤 추적) 카카오톡 채널 / 무료 레벨테스트 신청 버튼
- 히어로, 회사소개 요약, 강사소개(클릭 시 음성+상세 소개 모달), 학습시스템(내 강의실·학습평가서·매월 레벨평가), 수강절차, 수강후기, Why HiFive, 가격표 섹션
- 하단 푸터: 로고/회사명, 사이트맵 링크, 고객센터 및 사업자 정보

로그인/레벨테스트 신청/아이디·비밀번호 찾기는 백엔드 연동 전 프런트엔드 데모(mock) 상태입니다.
GNB에서 아직 만들지 않은 하위 페이지(회사소개 상세, 프로그램 설치 안내, 커리큘럼, 공지사항, 1:1 상담, 관리자/강사 페이지 등)는 "준비 중" 플레이스홀더로 연결되어 있습니다.
